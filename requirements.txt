# Live Caption Overlay

A real-time floating system-audio caption and translation overlay for Windows built with Python, `faster-whisper`, `PyAudioWPatch`, and `Tkinter`. It captures desktop/system audio via WASAPI loopback, stabilizes rolling speech hypotheses with a local agreement buffer, and renders crisp floating subtitles with a subtle drop shadow and hover-only controls.

## Features

- **System Audio Loopback Capture:** Captures desktop output audio (videos, streams, meetings, games) on Windows using WASAPI loopback without needing a microphone.
- **Local GPU Transcription (`faster-whisper`):** Runs Whisper models locally (`small`, `medium`, `large-v3-turbo`) with VAD filtering (`silero` / `faster-whisper` VAD) and silence/idle reset handling.
- **Rolling Stabilization (`LocalAgreement`):** Anchors on confirmed tail words across sliding inference windows so subtitles stay readable instead of constantly rewriting.
- **Optional Translation Modes:** Supports native Whisper translation to English (`to_en`) and phrase-level translation to a target language (`target`, e.g., `bn`) via `deep-translator`.
- **Floating Overlay & Hover Controls:** Uses color-key transparency (`-transparentcolor`), Win32 click-through toggle, drag-to-move positioning, and a top control strip that appears only when hovering over the overlay.

## Requirements

- **OS:** Windows (WASAPI loopback and Win32 layered/click-through window APIs)
- **GPU (Recommended):** NVIDIA GPU with CUDA support for `float16` inference (`DEFAULT_DEVICE = "cuda"`, `DEFAULT_COMPUTE_TYPE = "float16"`)
- **Python:** Python 3.10+

You can adjust top-level constants at the top of live_caption_overlay_3.py:

DEFAULT_MODEL_SIZE: "small", "medium", or "large-v3-turbo"

DEFAULT_SOURCE_LANG: "auto" or a language code such as "en" or "bn"

DEFAULT_TRANSLATE_MODE: "none", "to_en", or "target"

TARGET_LANG: Target language code for "target" mode (default "bn")

MAX_SUBTITLE_WORDS: Maximum number of words shown in the active subtitle stream (default 11)

IDLE_CLEAR_SECONDS: Seconds of quiet before clearing idle captions (default 1.2)



Troubleshooting
No WASAPI loopback device found: Make sure an active default playback device is enabled in Windows Sound settings and isn't disabled/disconnected.

Click-through locked and mouse clicks pass through: Press Ctrl + Alt + C to turn click-through off.

large-v3-turbo translation mode note: large-v3-turbo is tuned for fast transcription rather than speech-to-English translation; switch to small (1) or medium (2) if using To EN mode.

High VRAM usage when switching models: CACHE_LOADED_MODELS defaults to False so the previous model is released before loading another.
